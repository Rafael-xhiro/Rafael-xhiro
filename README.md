## 📌 Proyectos

### 💊 Farmasonitas
App móvil de farmacia con tres roles de usuario (admin, cliente, repartidor).
- **Frontend:** Ionic 7 + Angular 17
- **Backend:** Firebase / Firestore
- Inventario y gestión de pedidos en tiempo real, sincronización con `onSnapshot`, CRUD completo por rol.

### 🌳 Plataforma Integral de Analítica de Parques y Áreas Verdes (Lima Norte)
Plataforma de BI para gestión de parques y áreas verdes.
- **Backend:** Flask
- **Base de datos:** Supabase / PostgreSQL
- **ML:** Isolation Forest, Random Forest, KMeans para predicción y detección de anomalías
- **Dashboard:** Looker Studio
- Desplegada en Render, presentada ante jurado académico.

- **Motor:** Unity 3D + C#
- **Hardware:** Oculus SDK
- **Backend:** Firebase

### 🏥 Clínica Salud Inteligente (Big Data Lab)
Proyecto de analítica en salud con pipeline completo de datos.
- SQL Server, importación de CSV, cálculo de KPIs
- Modelos de ML y visualización en Looker Studio
